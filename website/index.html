01 / THE BENCHMARK

Evaluate the interaction,
not just the final number.

A single gold answer can reward an agent for guessing one plausible reading. FinInteract pairs a default reading with a hidden intended reading, then evaluates whether the agent clarifies and uses the answer.

03 / FINDINGS

Asking is only
half the challenge.

Agents must ask a question that resolves the ambiguity, then carry that clarification into their answer. Mentioning the right category alone does not establish success.

GPT-5 · 173 INSTANCES

A large gap to supplied intent

Free interaction20.2%
Context + evidence oracle95.4%

Supplying the intended context and both evidence spans makes the task much easier. This is an oracle condition, not the performance of an autonomous agent.

QWEN3-14B · 173 INSTANCES · OPEN-MODEL STACK

Clarification can be trained

Base model32.4%
Category-guided SFT60.1%

End-to-end interaction accuracy improves with 231 non-benchmark demonstrations. The gain is concentrated in Chinese: 39.2→78.3%; English changes from 17.0→18.9%.

Read the results in context. The evaluation set is small and imbalanced (53 English, 120 Chinese), and language is confounded with filing regime. Every benchmark item is ambiguous. Results do not establish a calibrated decision about when to ask in deployment.
